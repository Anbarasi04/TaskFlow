 
# 🚀 TaskFlow – Team Task Management Platform

**TaskFlow** is a full-stack task management application built using the MERN stack. It helps teams organize projects, manage tasks, track progress, assign responsibilities, and collaborate efficiently in one place.

## ✨ Features

### 🔐 Authentication
- User registration and login.
- Secure authentication using JWT.
- Protected routes for authenticated users.

### 📊 Dashboard
- View project and task summaries.
- Track overall project progress.
- Get a quick overview of your work.

### 📁 Project Management
- Create and manage projects.
- Add team members to projects.
- Manage member roles and permissions.

### ✅ Task Management
- Create, update, and delete tasks.
- Assign tasks to team members.
- Set task priorities: Low, Medium, and High.
- Set due dates and track deadlines.
- Update task status:
  - 📝 To Do
  - 🔄 In Progress
  - 🎉 Done
- Drag and drop tasks between status columns.

### 👤 My Tasks
- View tasks assigned to the logged-in user.
- Filter tasks by status and priority.
- Search and sort tasks.
- Identify overdue tasks.

### 🔔 Notifications
- Receive task and project notifications.
- View unread notification counts.
- Mark individual and all notifications as read.

### 💬 Collaboration
- Add comments to tasks.
- Work together with project members.
- Manage project access based on user roles.

### 📱 Responsive Design
- Clean and modern user interface.
- Responsive layouts for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
- React.js 
- Node.js 
- Express.js 
- MongoDB 
- CSS
